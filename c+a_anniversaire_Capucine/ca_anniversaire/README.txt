# c+a ❤️ — Site anniversaire de Capucine

Projet statique HTML/CSS/JavaScript, pensé pour mobile.

## Contenu
- Page d'accueil avec question interactive
- Animation de cœurs
- Page anniversaire du 2 septembre 2026
- Galerie de 6 photos
- Page "Une petite lettre" à personnaliser
- Page "Nous deux"
- Page surprise
- Design rose/blanc et responsive

## Ajouter la musique
Quand tu m'enverras le fichier audio, place-le dans le dossier du projet (par exemple `music.mp3`) puis on pourra ajouter le lecteur/lecture automatique adaptée aux navigateurs mobiles.

## Modifier la lettre
Ouvre `index.html`, cherche la section `id="letter"` et remplace le texte par ta lettre.

## QR code
Le QR code devra pointer vers l'URL publique du site après hébergement. Il ne faut pas créer le QR code définitif avant d'avoir cette URL.
